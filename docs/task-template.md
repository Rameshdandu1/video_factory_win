# Task Contract

## Outcome

Describe the observable result.

## Scope

List allowed modules and files.

## Out of scope

List adjacent behavior that must not change.

## Inputs and outputs

Reference stable contracts and specifications.

## Constraints

Reference applicable ADRs, security limits, performance targets, and compatibility requirements.

## Done when

- Requested behavior is verified.
- Unit and applicable integration tests pass.
- Architecture, lint, format, and type checks pass.
- No unrelated files changed.
- Documentation is current.
